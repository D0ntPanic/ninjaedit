# Ninja Edit

Ninja Edit is a fast, lightweight terminal-based IDE designed for modern git-based workflows.

## Features

* Fast navigation with command palettes
* Background syntax highlighting that doesn't slow you down on large files
* Search large codebases quickly, with or without regular expressions
* Built-in git history and commit workflows
* External changes are merged with your unsaved changes, instead of having to pick one
* Build and run your programs with build configuration support for Cargo and CMake
* Quick access to a shell within the editor
* Code completion from small language-specific models that run locally (Rust so far)
